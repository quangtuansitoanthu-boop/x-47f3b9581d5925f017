# Bundled dedication-card font

The four `be-vietnam-pro-*.ttf` files are the 400, 500, 600, and 700 static
weights of **Be Vietnam Pro**, downloaded from the official Google Fonts
repository. They serve the application UI through `tokens.css` and the
downloadable dedication card, keeping Vietnamese typography available offline.
